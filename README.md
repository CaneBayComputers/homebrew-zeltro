# Homebrew tap for Zeltro

```bash
brew install --cask canebaycomputers/zeltro/zeltro
brew upgrade --cask zeltro
```

Zeltro is the desktop app for building and running projects with AI: [zeltro.build](https://zeltro.build). The easiest way to install it on a Mac, including [Zeltro CLI](https://github.com/CaneBayComputers/zeltro-cli), is the one-line installer on the site. The cask is updated automatically with each release from [zeltro-releases](https://github.com/CaneBayComputers/zeltro-releases).

Free for personal use; business use needs a license: [zeltro.build/commercial](https://zeltro.build/commercial).
